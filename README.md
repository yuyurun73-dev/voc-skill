# /voc — カスタマー × プロダクト 横断リサーチ スキル

ペイン名か商品名を渡すと、**カスタマーリサーチ**と**プロダクト(UM)リサーチ**を同時に回す Claude Code スキル。

## これは何か

- **Track A**（誰が・何に困っているか）… 生の声／購入意思決定／生活シーンを全ソース横断で採集
- **Track B**（何が売り物になるか）… 競合の Unique Mechanism を解剖し、自社UM候補が**本当にuniqueか**を機械照合で判定

**汎用スキル。** どのペイン・どの商材・どの市場にも使う。SKILL.md 内の膝サポーター／圧迫ソックスの例は、すべて実測から取れたワークト・エグザンプル。

## 特徴

| | |
|---|---|
| **捏造を機械的に落とす** | 全引用をコーパスにgrep照合。FAILは破棄。実測で「検索スニペットから救出した」引用2件が逐語不在で落ちた |
| **UMは証明して初めてUM** | 「良さそう」でなく競合コーパスに存在しないことを4段階で判定 |
| **ソース地図つき** | どのソースが通り、どれが落ちるかを実測で記録。Facebookが取れないことも正直に明記 |
| **日英の語り方の違い** | 距離・時刻・恥・恐怖の語られ方が言語で違う。片方を翻訳すると死ぬ |

## 使い方

```
/voc <ペイン or 商品> [競合ドメイン...] [JP|US|both] [--light]
```

```
/voc 変形性膝関節症 圧迫スリーブ JP
/voc いびき マウスピース both
/voc 耳鳴り 首マッサージャー JP --light
```

## インストール

```bash
mkdir -p ~/.claude/skills/voc
cp SKILL.md ~/.claude/skills/voc/SKILL.md
```

プロジェクト単位で使うなら `<project>/.claude/skills/voc/SKILL.md` に置く。

## 出力の使い先

リサーチ素材づくりまでが役割。アングル案・コピー案は作らない。
そこから先は VSL／ネイティブ広告／LP の制作スキルに渡す。
